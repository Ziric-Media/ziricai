## Gate 5 detail

| Crumb | Status | Outcome |
|-------|--------|---------|
| `canManageNetwork` permission | **decided: not added** | The Sarah Network listing, verification, subscriber events and connection management all use the existing **`canManageWorkspace`** (owner/manager) permission — shared by the portal UI (`js/portal/permissions.js`), the server (`defaultAuthorize` in `networkListingRoutes.js`) and the Sarah matrices. A separate key would add a third place that can drift (portal / server / Sarah) for no new capability today: there is no role that should manage the workspace but not its public network presence. Revisit when a distinct "marketing/network manager" role exists. Members (any role) can read; writes need owner/manager (tested for subscriber events). |
| Verification evidence upload via chat media token | **skipped (not easy / wrong trust model)** | `chatMediaService` tokens are HMAC-bound to a consumer **personId**, live in a process-local `Map` and are metadata-only; tenant staff are not consumer persons and evidence needs durable, scanned, tenant-scoped storage. Reusing it would mix trust domains. Evidence stays references-only (SNET-04). Proper fix = tenant-scoped signed upload + storage + malware scan. |
| Persist search stats | **done** | `networkSearchStats` now flushes daily counters to `networkSearchStats/day_YYYY-MM-DD` (15 s debounce in Firestore mode, on read in memory mode; no user ids; zero-result query text stored only when it does not look like an email/phone, path characters sanitised). `getDurableSearchStats({days})` and `GET /api/platform/network/v1/stats` → `search.durable` (last 7 UTC days) survive restarts; `search.scope` stays `in_process_since_restart` for the live view. Merge is read-then-write per replica (not transactional) and there is **no TTL sweep** of old day docs. |
| Subscriber notification stub (event log only) | **done** | `services/network/subscriberEventService.js`; `POST/GET /api/network/v1/orgs/:companyId/subscriber-events` (write = `canManageWorkspace`). Records an `announcement` / `notification` / `reminder` with the **audience size** (subscribed/connected relationships with valid consent; `wouldReceive` honours each user's My Organisations prefs). `status: "logged_only"`, `delivered: 0`, no recipient identifiers stored, 20 events/day/company, suspended or entity-less businesses refused. **Nothing is delivered** — a delivery worker is still the open SNET-07 gap. |
| Server-side block of test/demo tenants from the public directory | **done** | `isHardBlockedFromPublicDirectory` (`networkEligibility.js`): DEMO/SHOWCASE, TEST and ACCEPTANCE classes are filtered out of `listDiscoverCards` and fail `assertCompanyDiscoverable` (so also company chat entry) **even if a stored/seeded directory entry says public**; operator allow-list (`SARAH_NETWORK_PILOT_COMPANY_IDS`) wins; UNKNOWN is still gated at publish time only (not blocked at read, so existing tests/entries keep working); Client Zero and pilots are never blocked. Tests: `test/gate5-network-crumbs.test.mjs`. |
